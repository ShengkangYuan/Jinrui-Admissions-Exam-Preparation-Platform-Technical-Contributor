# 金瑞金鹰系统介绍 · 叙事逻辑

> 受众：学校管理者、教师、家长及合作方。目标：展示系统「学生端体验 + 教师端效率 + 技术底座」三位一体的高端一体化能力，建立信任与购买/落地意愿。基调：高端、专业、可信。

## 主线
封面 → 目录 → 系统一句话定位与核心规模 → 学生端（个人空间聚合 / 刷题 / 语言 / 冒险 / 面试，配徐禾欣真实截图）→ 教师端（智能导入 / 试卷组卷 / 学生管理，配 SVG 架构）→ 技术亮点 → 收尾。

## 逐页大纲
1. **封面**：金瑞金鹰系统 · 智能备考与学情分析一体化平台。副标：学生端 + 教师端双引擎 · 让每一次练习都被看见。
2. **目录**：六大板块（系统概览 / 学生端·个人空间 / 学生端·学习矩阵 / 教师端 / 技术底座 / 结语）。
3. **系统概览（hero）**：一句定位 + 4 个巨型数字（5 大学生端模块 / 320+ 学科题库 / 28 个冒险被动技能 / 多维度学情分析）。
4. **章节过渡·学生端**：「01 学生端 — 以学习者为中心的全场景空间」。
5. **个人空间聚合**：说明个人空间是统一入口（我的作业/成绩历史/学情分析/错题本），右侧放徐禾欣「个人空间·我的作业」截图。
6. **案例·我的作业与24h紧急区**：上截图（我的作业+紧急倒计时），下要点：DDL 由近到远、24h 内独立红色紧急区+实时倒计时、整卡开卷。
7. **案例·薄弱知识点 / 学情诊断（hero）**：大截图（薄弱知识点页面入口），数据卡：答题后自动生成雷达图与薄弱点排序；说明多维度（学科/难度/练习vs模考/知识点）。
8. **案例·成绩历史与错题本**：双截图并排（成绩历史趋势 + 错题本折叠解析），要点：往期表现、Band 报告、解析可折叠、标记掌握。
9. **刷题练习·试卷库**：左说明（学科/套题类型筛选、排序、整卡开卷、练习/模考），右徐禾欣试卷库截图。
10. **语言学习**：左说明（雅思/TMUA/ESAT 练习与模考、听力播放/阅读高亮/写作字数/口语录音），右徐禾欣语言试卷库截图。
11. **冒险模式**：左说明（Roguelike 即时战斗、28 个被动技能树、升级三选一、虚拟魔弹主动技），右徐禾欣冒险模式截图。
12. **面试练习**：左说明（模拟面试场景、即时反馈），右徐禾欣面试练习截图。
13. **章节过渡·教师端**：「02 教师端 — 把老师从重复劳动中解放出来」。
14. **教师端·智能导入（SVG）**：左 SVG 导入流水线（PDF→视觉模型识别题目+答案→按题号匹配→自动知识点归类→审核发布），右要点：视觉模型自动识别、答案按题号映射防错位、AI 自动生成解析。
15. **教师端·试卷与组卷（SVG）**：左 SVG 试卷管理架构（原版真题/自组卷、学科/套题类型筛选、从题库选题），右要点：一键组卷、审题发布铁律（缺答案禁发布）。
16. **教师端·学生管理（SVG）**：左 SVG 学生管理（学情统计/作业考试分发/到期自动过期/级联删除），右要点：DDL 分发、完成率统计、个人空间数据同源。
17. **技术底座（hero）**：五大亮点卡（视觉识别导入 / 即时判分引擎 / AI 解析生成 / 多维学情分析 / Roguelike 战斗引擎），金强调。
18. **结尾**：金句「金瑞金鹰 · 让成长有迹可循」。落款：金瑞升学 · 金鹰系统。
