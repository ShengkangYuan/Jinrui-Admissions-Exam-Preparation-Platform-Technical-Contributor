# 学生端测试用例(手动)

> 系统:金瑞升学金鹰系统
> 前置:后端(http://localhost:4000)与前端(http://localhost:3000)均已启动
> 演示学生账号:`stu@example.com` / `123456`(也可用下方 TC-01 注册新账号)

---

## 快速验证(1 分钟)

1. 浏览器打开 **http://localhost:3000**
2. 用 `stu@example.com` / `123456` 登录
3. 主页选「练习 / 5 题 / 全部」→ 开始练习 → 作答 → 交卷 → 查看成绩与解析
4. 点顶部「错题本」看答错的题 →「成绩历史」看记录

---

## 完整用例

### TC-01 注册新账号
| 项 | 内容 |
|----|------|
| 步骤 | 访问 /login → 切到「注册」→ 填姓名/邮箱/密码(≥6 位)→ 提交 |
| 预期 | 跳转到学生主页;右上角显示你的姓名 |

### TC-02 登录
| 项 | 内容 |
|----|------|
| 步骤 | 退出后重新登录(邮箱/密码) |
| 预期 | 登录成功进入学生主页 |

### TC-03 学生主页
| 项 | 内容 |
|----|------|
| 步骤 | 观察主页各卡片 |
| 预期 | 顶部欢迎语;「开始练习」表单(模式/试卷/科目/题量/时长);有成绩后出现「成绩趋势折线图」「知识点掌握度雷达图」「最近成绩表」 |

### TC-04 开始练习(随机组卷)
| 项 | 内容 |
|----|------|
| 步骤 | 模式=练习、试卷=随机组卷、科目=TMUA、题量=5 → 开始练习 |
| 预期 | 进入答题页,共 5 题;顶部显示「已答 0/5」;题目含知识点/难度标注 |

### TC-05 答题页(公式与图片)
| 项 | 内容 |
|----|------|
| 步骤 | 观察题干与选项渲染;点击选项选中;用答题卡跳题 |
| 预期 | 数学公式渲染为专业排版(如 √、分数、上标);图形题(卡片/函数图)显示图片;选中选项高亮;答题卡数字变蓝(已答) |

### TC-06 提交判分与解析
| 项 | 内容 |
|----|------|
| 步骤 | 全部作答后点「交卷」→ 确认 → 查看结果页 |
| 预期 | 显示得分(答对/总分);每题标注对错;选项标出正确答案;下方显示「解析」 |

### TC-07 成绩历史
| 项 | 内容 |
|----|------|
| 步骤 | 顶部「成绩历史」→ 查看列表 |
| 预期 | 每次练习/模考一行:模式、得分、正确率、时间;可按模式筛选;点「查看」回到该次结果页 |

### TC-08 错题本与标记掌握
| 项 | 内容 |
|----|------|
| 步骤 | 顶部「错题本」→ 查看;点某题「标记掌握」 |
| 预期 | 答错的题出现在「待掌握」分组(显示错次数与题干);标记后移入「已掌握」分组 |

### TC-09 模拟考(限时)
| 项 | 内容 |
|----|------|
| 步骤 | 主页模式=模拟考、时长=25 分钟、题量=5 → 开始模拟考 |
| 预期 | 答题页顶部出现红色倒计时;最后 5 分钟出现黄色提醒;时间到自动交卷并提示「考试时间已到,系统已自动交卷」;结果页显示 timedOut 提示 |

### TC-10 使用官方试卷
| 项 | 内容 |
|----|------|
| 步骤 | 主页「试卷」下拉选择「TMUA 全真模拟」(或其它试卷)→ 开始 |
| 预期 | 会话使用该试卷的固定题目与限时(模拟卷带倒计时);试卷题全部来自官方真题(题干含 TMUA Specimen 来源标注) |

### TC-11 数据可视化
| 项 | 内容 |
|----|------|
| 步骤 | 完成至少 2 次练习后回到主页;完成 ≥3 个知识点的作答 |
| 预期 | 「成绩趋势折线图」显示正确率曲线(≥2 次时);「知识点掌握度雷达图」显示各知识点正确率多边形(≥3 知识点时);鼠标悬停显示数值 |

### TC-12 退出登录
| 项 | 内容 |
|----|------|
| 步骤 | 右上角「退出」 |
| 预期 | 回到登录页;刷新后无法直接访问学生页(自动跳回登录) |

## 自动化冒烟测试(可选)

后端已跑通全链路自动化验证(注册→刷题→判分→错题本→模考→权限,20 项断言):

```bash
cd apps/api && npm run smoke
```

预期输出:**通过 20 项,失败 0 项**。

## 常见问题排查

| 现象 | 处理 |
|------|------|
| 页面空白 | 先登录;或后端未启动(检查 http://localhost:4000/api/health) |
| 图片/公式不显示 | 刷新页面;确认访问的是 http://localhost:3000(而非直接打开文件) |
| 报「无法连接服务器」 | 重启后端:`cd apps/api && npm run dev` |
